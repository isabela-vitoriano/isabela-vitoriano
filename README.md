## Sobre mim 💼
Engenheira de Dados com mais de 4 anos de experiência na construção e manutenção de pipelines de dados, atuando em diferentes segmentos como e-commerce e people analytics.

Atualmente, na enjoei, desenvolvo e mantenho pipelines de dados batch e near real-time orquestrados com Airflow, com atenção à qualidade dos dados ao longo de todo o fluxo. Faço modelagem de dados e otimização de tabelas no BigQuery, buscando melhor performance e menor custo, além de integrar APIs de parceiros e diferentes bancos de dados para ingestão.

Tenho vivência prática como engenheira de dados em AWS, GCP e Azure, além de Databricks para criação de notebooks e processamento de dados em larga escala.
